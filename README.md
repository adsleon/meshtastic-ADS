# meshtastic-ADS

Repositorio para centralizar y versionar los materiales de soporte, documentación
y recursos necesarios para el desarrollo del proyecto Meshtastic desde ADS.

## Descripción

Este repositorio agrupa presentaciones, documentos, imágenes y otros
recursos didácticos y técnicos relacionados con la integración y el
desarrollo de Meshtastic en el ámbito de ADS. Su objetivo es facilitar la
colaboración entre miembros del equipo, mantener trazabilidad de los
materiales y ofrecer una referencia única para actividades de enseñanza,
despliegue y pruebas.

## Tabla de contenidos

- **doc/**: documentación, presentaciones y material para formación.
- **img/**: recursos gráficos y capturas.
- `LICENSE`: licencia del repositorio.
- `README.md`: este documento.

## Requisitos

No hay dependencias de software específicas para los materiales, solo un
visualizador de documentos (PDF, PowerPoint) y herramientas habituales de
edición de imágenes si desea modificar recursos gráficos.

## Uso

1. Clonar el repositorio:

	git clone https://github.com/tu-organizacion/meshtastic-ADS.git

2. Abrir las presentaciones en `doc/Presentaciones` con tu visor preferido.
3. Revisar las imágenes y recursos en `img/` y `doc/` según la necesidad.

## Contribuir

Las contribuciones son bienvenidas. Siguiendo este flujo básico:

1. Crear un fork y una rama con nombre descriptivo (`feature/`, `fix/`, `docs/`).
2. Realizar cambios y comprobar que los archivos añadidos siguen la estructura.
3. Abrir un Pull Request describiendo los cambios y su propósito.
